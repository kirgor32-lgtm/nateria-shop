# Задача: ребрендинг hvostik-shop-minimal → Nateria

## Контекст
Поставщик снимает бренд «Хвостик» с производства, его сменяет новый бренд **Nateria** (линейки
кормов для кошек и собак). Нужен полноценный B2C интернет-магазин для Nateria — такого же уровня
качества (UI/UX, usability), как действующий `hvostik-shop-minimal` (стиль «Контур»: тонкая обводка
`border border-ink`, `rounded-[2px]`, никаких теней/градиентов/эмодзи-пилюль).

Этот каталог (`D:/projects/nateria-shop`) — ПОЛНАЯ КОПИЯ архитектуры `hvostik-shop-minimal`
(React 19 + Vite + Tailwind 4, SSR-prerender, localStorage демо-аккаунты/корзина/избранное, CRM-hook
в `src/crm.js`/`src/auth.js` — в демо-режиме, не трогать протокол). Твоя задача — переделать её под
новый бренд, используя РЕАЛЬНЫЕ данные каталога из `nateria_catalog.json` (15 SKU: 8 для кошек,
7 для собак, у каждого 3 фасовки с ценой для ТТ/РРЦ и штрихкодом — см. поле `price_estimated: true`
у одной позиции («Индейка и брусничный лист. Профилактика МКБ», собаки) — это единственная SKU,
где прайс-лист поставщика был физически битый (copy-paste сдвиг строк), для неё взята цена
аналогичной по рецепту позиции «Индейка и клюква. Профилактика МКБ» как разумная оценка. Это
нормально для сайта, но держи комментарий в коде/README, что цену нужно подтвердить у поставщика.

## Что сделать

### 1. База/пути
- Новый репозиторий: `kirgor32-lgtm/nateria-shop` (уже создан, origin настроен).
- GitHub Pages адрес: `https://kirgor32-lgtm.github.io/nateria-shop/`
- Замени ВСЕ упоминания `/hvostik-minimal/` → `/nateria-shop/` (vite.config.js base, index.html
  favicon/manifest ссылки, src/data.js BASE/SITE).
- `src/auth.js` / `src/crm.js` — просто замени комментарии-примеры доменов (hvostik.ru →
  nateria... не обязательно реальный домен, просто для consистентности), сам демо-режим не трогай.

### 2. Бренд / визуал
- Название бренда везде: **Nateria** (можно писать и кириллицей «Натерия» в тексте для читателей,
  но логотип/название бренда — латиницей Nateria, как в прайс-листе поставщика).
- Полностью убери все следы «Хвостик»/paw-print лого/красный #d6352a. Нужен НОВЫЙ визуальный язык
  для Nateria — предложи свою палитру (не копируй бренд-гайд хвостика бездумно), но ОСТАВЬ сам
  принцип "Контур" (тонкие обводки border-ink, rounded-[2px], без теней/градиентов) — он уже доказал
  себя как чистый, премиальный стиль для категории petfood. Подбери контрастный, премиальный акцент
  (например тёплый терракотовый/оливковый/графитовый — на твой дизайнерский вкус, с проверкой
  WCAG контраста >=4.5:1 на белом для текста/обводок). Новый логотип: текстовый wordmark «NATERIA»
  (uppercase, letter-spacing) — без иконки животного, подчёркивающий премиальность/натуральность
  (возможно + простой геометрический акцент: лист, зерно, капля — на твой выбор, в стиле "контур").
  Перегенерируй favicon/иконки под новый лого (см. референс `references/icons-favicons.md` в скилле
  hvostik-shop-deploy, если нужна техника растеризации).

### 3. Каталог
- Замени товары в `src/data.js` (products array) на 15 SKU из `nateria_catalog.json`
  (поля: id, name, tag, composition, nutrition, granule, weights[{w, barcode, tt, rrc,
  price_estimated?}]). Разбей на 2 категории: кошки / собаки (как у Хвостика было МЯУ/ГАВ —
  здесь просто "Кошкам"/"Собакам").
  - Цена на сайте = `rrc` (это розничная цена, с которой покупатель реально платит); `tt`/штрихкод
    не показывать покупателю на витрине, но можно вывести на карточке товара мелким текстом рядом
    с составом (штрихкод — не обязательно, по желанию дизайна).
  - Состав (`composition`) и питательная ценность (`nutrition`) — показать как в hvostik карточках
    товара (состав с раскрытием «Показать полный состав», питательная ценность — таблица: белок,
    жир, клетчатка, зола, кальций, фосфор, ккал).
  - Используй `tag` как бейдж категории на карточке (например «Профилактика МКБ»,
    «Гипоаллергенный», «Для котят», «Чувствительное пищеварение» и т.п.).
  - Пока нет реальных фото паков — используй простые placeholder-пакеты/иллюстрации в стиле
    "Контур" (как было у hvostik, минималистичные векторные paw-free изображения мешков корма с
    принтом названия и акцентным цветом), НЕ выдумывай фото которых нет.
  - Производитель (карточка товара/подвал/страница "О бренде"): ООО «СКЗ», 410010, Саратовская
    область, г. Саратов, ул. им. Осипова В.И., зд.1, пом. 39/12; производство — г. Саратов, ул. им.
    Спицина Б.В., з/у 1А. Срок годности 18 месяцев. ГОСТ Р 55453-2022. Условия хранения — из
    nateria_catalog.json → manufacturer. НЕ выдумывай других фактов о бренде/истории — если для
    "О бренде" не хватает конкретики, пиши честно и нейтрально про состав/качество/производство,
    без придуманных историй основания компании.

### 4. Функциональность — перенести как есть из hvostik-shop-minimal
Корзина, избранное, чекаут (телефон+код демо, профиль, адрес/пункт выдачи 5Post демо), личный
кабинет, промокод, сравнение состава, карточки с выбором фасовки (mt-auto паттерн), footer 2-col
на мобиле, cookie-банер, вся accessibility/mobile-полировка (touch-action, 16px inputs, scroll
restoration и т.д.) — это всё уже в коде, просто поменяй тексты/цвета/картинки/данные, НЕ лома
работающую логику.

### 5. Копирайт (новый, не копировать тексты хвостика 1:1)
Напиши свою тёплую, но не инфантильную подачу под премиальный petfood-бренд Nateria: hero-баннер,
микротексты пустых состояний корзины/избранного, подписи к CTA (без putно-игривых двойных смыслов
на кнопке оформления заказа — см. правило "CTA/action buttons: clarity beats the warm register" в
skill hvostik-shop-deploy, это применимо и здесь).

### 6. QA перед деплоем
- `npm run build` должен проходить без ошибок.
- Прогнать mobile-viewport чек (320–1440) на главной/каталоге/карточке/чекауте — не должно быть
  горизонтального скролла/наезжающих элементов (используй тот же grid-audit подход, что в hvostik).
- Убедиться что все 15 SKU и 45 фасовок (15×3) отображаются и ведут в корзину/чекаут корректно.

### 7. Деплой
Build → commit в main → `npx --yes gh-pages@6.3.0 -d dist -m "deploy"` в gh-pages ветку того же
репозитория (как в skill hvostik-shop-deploy). Финальный адрес должен открываться и показывать
новый сайт Nateria.
